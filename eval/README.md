45장 (26 에피소드, 데이터셋 씬 카메라 `follower_d455f`).
라벨은 컨택트 시트를 눈으로 보고 직접 붙였다.

### 1. 물체 인식

```
실제\예측       tree  flower   whale    none   정확도
tree          11       0       0       0   100.0%
flower         0       8       0       1    88.9%
whale          0       0      11       0   100.0%
none           0       0       0      14   100.0%

전체 44/45 = 97.8%
```

- **방해자극 누출 0건** — 체크리스트에 없는 것을 tree/flower/whale 로 부른 적이 없다
- **물체를 다른 물체로 잘못 부른 경우 0건** — 유일한 오답은 flower→none(보류)이고,
  로봇이 움직이지 않는 안전한 방향이다
- 그 오답(ep012)은 사람 손이 물체를 막 놓는 순간의 경계 프레임이다.
  실제 배치에서는 **아동이 물러난 뒤** 운영자가 캡처를 트리거하므로(§5) 이 순간이 오지 않는다

### 2. 호출 판단
44/45 = 97.8%. 운영자 보류 15/45.

### 3. 지연 — **예산 미달**
```
중앙 3.90s / 평균 4.18s / p95 6.50s / 최대 9.74s
T_judge ≤ 3초 충족: 2/45 = 4%
```
이미지 크기는 병목이 아니다:

| 가로 | 업로드 | 중앙 지연 | 예측 일치 |
|---|---|---|---|
| 512px | 30.3KB | 4.04s | 기준 |

## 라벨링 주의

첫 라벨링에서 5장을 틀렸다 (ep003·012·013·038·039). 축소 이미지에서는 "손이 물체를
들고 있다"로 보였지만 확대하니 물체는 이미 배치면 위에 있었고 손은 떨어지는 중이었다.
**VLM 이 5건 모두 맞았고 사람이 틀렸다.** 경계 프레임은 반드시 확대해서 판정할 것.

## 아직 검증 안 된 것

- **방해자극(`other`) 실측** — 이 세트에는 방해자극 사진이 없다. 부록 B가 요구하는
  20~30장을 찍어야 `other` 정확도가 측정된다. 지금 "누출 0건"은 방해자극이 등장하지
  않았다는 뜻이지, 잘 거른다는 증거가 아니다
- **조명 조건** (커튼 개폐) 분해
- **가방에 물건이 여러 개 든 상태**에서 배치면 물체만 골라내는지 — 프레임은 있으나 라벨 미부여
